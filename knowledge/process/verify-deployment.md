# Static install verification

Resolve the exact Git root and active hook, verify any chained predecessor,
compare installed artifacts and executable modes to the canonical template,
confirm parser/runtime/schema hashes and preserved controls, and prove no
parent-workspace call, runtime fetch, scheduler, service, Factory task, or
background artifact exists. Portable search must work without `.okf`; semantic
commands must fail closed when their local runtime is unavailable.

# Combined contract suite

Run the canonical aggregate suite serially. It covers schema and generated
validator parity, parser, linter, capture quality/override, inbox status and
triage, bounded run safety, curator preflight/staging/postflight/failure/resume,
typed viewer, semantic query plus portable fallback, reversible archive and
rollback, manual cadence observation, runtime packaging, and fresh/reinstall
installer behavior.

Failure scenarios include unsafe roots/symlinks, malformed YAML, duplicate IDs
and tags, unresolved relationships, raw/oversized capture bodies, live/stale
locks, kill switch, quotas, cancellation, changed resume inputs, invalid staged
output, postflight failure, archive partial states, and parser-unavailable
fallback. Reports and warnings must not copy raw secret-bearing input.

# Operational canaries

Use frozen tracked snapshots for small `designs`, medium active-project, and
bounded large-backlog datasets. Record exact source revisions and hashes,
declared ceilings, source preservation, strict validation, retrieval,
usefulness/yield, runtime/CPU/disk/generated bytes, one session/concurrent run,
failure recovery, operator intervention, and live-root non-mutation. D7 then
evaluates the hashed reports over a defined manual observation window. No
successful snapshot authorizes a live mutation or broader rollout.

# Completion boundary

Deployment is complete only when the aggregate suite, installer fixture,
operational canaries, cadence observation, Git diff checks, and contract audit
are green. Broader adoption is a separate explicit approve/revise/stop decision;
no hosted deployment is implied.
